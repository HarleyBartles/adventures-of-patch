# assets/hero-patch/Detective index

Patch Detective role kit asset-sheet package.

This folder holds the deterministic sheet, the sheet spec, the sidecar, and the nested approved source-image set for the Patch detective variant.

## Files in this directory

- `README.md` - canonical human-readable package summary and companion status note.
- `asset_sheet_sidecar.md` - human-readable summary for the Patch Detective role kit.
- `asset_sheet_spec.json` - deterministic compile spec for the Patch Detective role kit.
- `asset_sheet__character__patch_detective_role_kit_v1.png` - rendered Patch Detective role kit sheet.
- `template_final_asset_sheet_blank_v4.png` - approved v4 asset-sheet template used for the compile.

## Subdirectories

- `source_images/` - approved source images for the Patch detective package. See `source_images/INDEX.md`.

## Notes for agents

This is a Patch costume-variant sheet package, not a new Patch canon. Keep the teal hoodie, antennae, black oval eyes, and crossbody bag language intact when using this family as reference.
