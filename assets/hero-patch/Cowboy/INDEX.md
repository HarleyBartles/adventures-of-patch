# assets/hero-patch/Cowboy index

Patch Cowboy role kit asset-sheet package.

This folder holds the deterministic sheet, the approved source images, the sheet spec, and the sidecar for the Patch cowboy variant.

## Files in this directory

- `asset_sheet_sidecar.md` - human-readable summary for the Patch Cowboy role kit.
- `asset_sheet_spec.json` - deterministic compile spec for the Patch Cowboy role kit.
- `asset_sheet__character__patch_cowboy_role_kit_v1.png` - rendered Patch Cowboy role kit sheet.
- `source_hero_patch_cowboy_waistcoat.png` - hero source image for the cowboy variant.
- `source_alt_01_side_view.png` - cowboy side-view source image.
- `source_alt_02_back_view.png` - cowboy back-view source image.
- `source_alt_03_lasso_pose.png` - cowboy action pose source image.
- `source_alt_04_close_view.png` - cowboy close-view source image.
- `source_alt_05_details.png` - cowboy details source image.
- `source_alt_06_props.png` - cowboy props source image.
- `template_final_asset_sheet_blank_v4.png` - approved v4 asset-sheet template used for the compile.

## Subdirectories

None.

## Notes for agents

This is a Patch costume-variant sheet package, not a new Patch canon. Keep the teal hoodie, antennae, black oval eyes, and crossbody bag language intact when using this family as reference.
