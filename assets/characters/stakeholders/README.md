## Family

## Package shape

## Current status

approved_preproduction_reference

## Intended use

Reusable stakeholder reference family for decks that need accountable human counterparties with defined function, proof, risk, and approval roles.

## Guidance

Select stakeholders because the story needs their function. Do not add them unless the deck benefits from clearly accountable human counterparties.
