# Guidance Balance Scenes

Approved exploratory scene set for a possible future Goldilocks-themed Adventures of Patch deck.

## Purpose

This pack preserves three accepted Patch-led scene images that express a guidance-balance pattern:

1. **Too much** — Patch is overloaded with tools, maps, notes, instructions, and conflicting guidance until he cannot move or decide.
2. **Not enough** — Patch has only a vague instruction while facing many valid next moves.
3. **Just right** — Patch has access to plentiful, clearly organised resources and can confidently choose what he needs.

These images are reusable adventure scene assets. They are not yet bound to a specific issue, slide order, or finished deck.

## Accepted image filenames

When the approved PNGs are added, place them in:
