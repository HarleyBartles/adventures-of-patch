## Packet posture

This framework is a composable style system. It should be used to decide visual preproduction order, create prompt boards, draft style references, and prevent drift. It should not be treated as image-generation authority or as final locked visual canon.

The bibles are intended to be updated after visual evidence exists. If accepted visuals contradict this packet, decide whether the image is wrong, the bible is wrong, or the issue direction has changed. Do not silently accept contradictions.

## Bible taxonomy

Use the packet layers by ownership:

- **Style bibles** own global world, global frame rules, Patch adaptation, crew ontology, props, environments, planning, and deck-level montage.
- **Frame bibles** own character-specific panel/frame/superframe grammars.
- **Character bibles** own character identity, recruitment language, posture, payoff mechanism, character negatives, and character QA.
- **Source** preserves historical combined material and should not be treated as the active prompt surface unless a later task explicitly needs provenance.

Do not put detailed transition catalogues into character bibles. If a visual rule describes how panels, frames, gutters, borders, documents, observation windows, receipt rolls, or decision grids behave, it belongs in a frame bible or global frame bible.
