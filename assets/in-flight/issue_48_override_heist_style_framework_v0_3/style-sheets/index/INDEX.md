## Notes for agents

This folder is the discoverability surface for the local image-plus-sidecar pair set. The JSON sidecars live next to the PNGs and use the same basename with `-sidecar.json`.
The local `schema.v0.1.json` file documents the adjacent-sidecar contract used by this folder.
