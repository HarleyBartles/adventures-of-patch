## Cross-recruit recruitment structure

Each recruit slide repeats the same structural lesson from a different angle: Patch asks; the recruit's domain reveals the missing lawful layer; the recruit's own system delivers or validates the assent; the repeated recruitment beat becomes proof that a single thought pattern is not enough.

- Index proves the need for source/provenance.
- Silk proves the need for adversarial pressure testing.
- Rollback proves the need for contingency and recovery.
- Writ proves the need for lawful authority.
- Klause proves the need for decision discipline.
- Receipt proves the need for auditability.
