# assets/evidence index

Receipt, import, transfer, and legacy evidence for Adventures of Patch.

This root holds evidence packages that are not canonical input zips. Use it for receipt bundles, imports, transfers, and other provenance that should stay visible but separate from source-import packaging.

## Files in this directory

None.

## Subdirectories

- `receipts/` - receipt evidence packages. See `receipts/INDEX.md`.

## Notes for agents

Do not treat evidence packages as canonical input zips. Evidence can support provenance, but it is a separate lane from `assets/source-zips/`.
