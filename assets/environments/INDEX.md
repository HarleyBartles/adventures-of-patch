# assets/environments index

Environment and location asset families for Adventures of Patch.

## Files in this directory

No direct environment files are expected at this level. Navigate into subdirectories.

## Subdirectories

- `club-db/` - Club DB reusable optional environment family. See `club-db/INDEX.md`.
- `identity-emporium/` - Identity Emporium reusable environment family. See `identity-emporium/INDEX.md`.
- `mission-control/` - Patch Mission Control Centre reusable environment family. See `mission-control/INDEX.md`.

## Notes for agents

Environment families are optional. Do not force an existing environment into a deck if the adventure needs a new setting.
