## What changed in v0.3

This packet keeps the original inner folder layout and adds a new `frame-bibles/` layer.

The v0.2 packet correctly decomposed the visual framework, but the character bibles were carrying too much panel/frame grammar. Silk's bible was especially overloaded: it contained both character identity and a detailed frame-transition catalogue. v0.3 separates those concerns:

- `style-bibles/` own global systems.
- `style-bibles/04_composable_panel_framing.md` is the global frame/panel/superframe bible.
- `frame-bibles/` own character-specific panel/frame grammars.
- `character-bibles/` own character identity, recruitment posture, payoff language, and character QA.
- `source/` preserves the original combined source packet unchanged.
