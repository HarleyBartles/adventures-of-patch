# Patch directory guidance

This directory holds Patch actor governance, routing, contracts, ingress notes, and Patch-owned executable capabilities.

When working in `Patch/`, start with:

1. `../INDEX.md`
2. `../AGENTS.md`
3. this file
4. `README.md`
5. `GOVERNANCE.md`
6. `ROUTING.md`
7. `CONTRACTS/WORKER_RETURN_CONTRACT.md` when tracked repo mutation may occur
8. `SKILLS/INDEX.md`

Use the local `INDEX.md` mesh before broad search. Keep actor governance separate from Patch visual canon under `assets/canon/patch/`.
