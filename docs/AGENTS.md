# docs directory guidance

This directory holds project documentation, adventure concepts, principles, and workflow notes.

When working in `docs/`, start with:

1. `../INDEX.md`
2. `../AGENTS.md`
3. this file
4. `INDEX.md`
5. `project/INDEX.md`
6. the relevant child directory `INDEX.md`

Use `docs/project/` as the first-class navigation surface for repo-grounded project work inside documentation.
