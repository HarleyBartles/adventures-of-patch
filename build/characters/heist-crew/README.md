# Heist Crew character reference pack

This is the first-class character home for Index, Silk, Writ, Klause,
Rollback, and Receipt. The package contains only accepted visual references
and character-continuity material promoted from the Override Heist workbench.
Adventure-specific frame grammar, pitch-folder sequence art, source snapshots,
experiments, drafts, and rejected generations remain in the workbench.

## Continuity hierarchy

For each character, use the hero image as the primary single-pose reference,
the style sheet for turnaround and kit consistency, and the anti-pattern sheet
only as a visibly rejected negative-control reference. The adjacent sidecars
record observed visual facts, constraints, acceptance state, and the provenance
known for each image.

The shared character-class bible and the available character bibles live in
`manifests/`. Index has no separate checked-in character bible; use Index's
three accepted references and adjacent sidecars together with the shared
character-class bible. Do not reconstruct a missing Index bible from the
historical workbench source packet.

Adventure-specific panel and recruitment-frame grammar remains under
[`workbench/issue_48_override_heist_style_framework_v0_3/frame-bibles/`](../../../workbench/issue_48_override_heist_style_framework_v0_3/frame-bibles/INDEX.md).
