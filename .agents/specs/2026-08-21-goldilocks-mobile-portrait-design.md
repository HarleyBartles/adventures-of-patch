# Goldilocks: mobile portrait fairytale page

## Problem

The approved 2400 x 1350 (16:9) Goldilocks fairytale page is not usable on mobile. The three side-by-side panels shrink to unreadable size in a portrait browser. We need a deterministic 9:16 portrait PNG that preserves the same information and feels like the same page re-flowed, not a different image.

## Constraints

- No image generation; only Pillow-style deterministic composition.
- Must keep all existing wording and the same three scenes.
- Must look like an alternate layout of `page__right_amount_of_guidance__v1.png`.
- Must pass `py -3 tools/run.py ci --check` after landing in the repo.

## Source assets

- `published/fairytales/goldilocks/scene__too_much__v1.png` (too much)
- `published/fairytales/goldilocks/scene__not_enough__v1.png` (not enough)
- `published/fairytales/goldilocks/scene__just_right__v1.png` (just right)
- Existing page `published/fairytales/goldilocks/page__right_amount_of_guidance__v1.png` for color reference

## Output

- `published/fairytales/goldilocks/page__right_amount_of_guidance__v1-mobile.png`
- Adjacent `adventures.visual_sidecar.adjacent.v1` sidecar generated by `tools/generate_image_sidecar.py`
- Manifest updated to list `finished_page_mobile`

## Visual design

### Canvas

- 1080 x 1920 px, RGB, white/cream background
- Portrait 9:16, matching typical phone viewport

### Color palette (sampled from the 16:9 page)

- Background: `#f7f4ec` (247, 244, 236)
- Title/body text: `#1d2b3a` (29, 43, 58)
- "PATCH FAIRYTALES" label: `#0e8d84` (14, 141, 132)
- "THE LESSON" label: `#be912f` (190, 145, 47)
- White: `#ffffff`
- Card border/shadow: `#1d2b3a` with subtle rounded rectangle

### Typography

- Title: bold sans-serif, 56 pt
- Subtitle: regular sans-serif, 32 pt
- Scene label (TOO MUCH / NOT ENOUGH / JUST RIGHT): bold sans-serif, 24 pt, uppercase
- Scene caption: regular sans-serif, 24 pt
- Lesson label: bold sans-serif, 24 pt
- Lesson body: regular sans-serif, 26 pt
- Fallback font: `C:\Windows\Fonts\arial.ttf` / `arialbd.ttf` (the repo is developed on Windows)

### Layout

1. **Header** (top 180 px)
   - "PATCH FAIRYTALES" in teal, left-aligned, top-left corner
   - "Goldilocks and the Right Amount of Guidance" in dark text, left-aligned
   - "Too much. Not enough. Just right." in dark text, smaller

2. **Three stacked scene rows** (each ~400 px tall)
   - Each row is a rounded card with a subtle border, 60 px horizontal margins, 20 px top/bottom
   - Left side (60% width): the scene image, scaled to fill height, aspect-preserved, 16:9 crop if needed
   - Right side (40% width): the scene label and the caption, vertically centered, wrapped to fit
   - Reading order remains too much, not enough, just right

3. **Lesson bar** (bottom 220 px)
   - "THE LESSON" in gold/brown, uppercase, bold
   - "Good agent guidance is not maximum context. It is enough relevant context for a confident next decision." in dark text

## Tool and script

A new deterministic build script `tools/build_fairytale_mobile_page.py` with a `goldilocks` hard-coded recipe. It is a one-off builder, not a generic framework.

## Implementation steps

1. Load the three source PNGs.
2. Resize each to a 560 x 315 px 16:9 image using `Image.LANCZOS`.
3. Create 1080 x 1920 canvas and fill with `#f7f4ec`.
4. Draw header text.
5. For each scene, paste the image on the left, draw the rounded card border, draw the label and caption on the right.
6. Draw the lesson bar.
7. Save as `page__right_amount_of_guidance__v1-mobile.png` in `published/fairytales/goldilocks/`.
8. Generate the sidecar with `py -3 tools/generate_image_sidecar.py <image_path>`.
9. Update `manifest.json` to add `finished_page_mobile: page__right_amount_of_guidance__v1-mobile.png`.
10. Run `py -3 tools/run.py ci --check` and `py -3 tools/run.py ci --apply` if generated surfaces need to be refreshed.

## Validation

- Visual diff/inspection against the 16:9 page for color and text parity.
- `tools/run.py ci --check` passes.
- Sidecar validates.
