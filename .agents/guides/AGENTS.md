# Stage guide routing

These four files are thin repository overlays. Read the matching portable
baseline and Superpowers skill first; use this directory only for Adventures
paths, exclusions, commands, and gates.

- `design-guide.md` — frame and visual-design decisions.
- `planning-guide.md` — issue and adventure-readiness planning.
- `implementing-guide.md` — repo mutation and deterministic validation.
- `code-review-guide.md` — review and publication evidence.

Do not put durable law here. Put it in `.agents/doctrine/` and regenerate the
mesh after routing changes.
