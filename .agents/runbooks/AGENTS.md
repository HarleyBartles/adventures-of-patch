# runbooks directory guidance

This directory holds first-class Adventures of Patch project and domain operating doctrine.

When working in `.agents/runbooks/`, start with:

1. `../INDEX.md`
2. `../AGENTS.md`
3. this file
4. `INDEX.md`
5. the relevant runbook file

Keep project workflows in runbooks rather than burying them inside agent
infrastructure. Put repo-local executable capabilities under `.agents/skills/`
and keep Patch-specific visual canon under `assets/canon/patch/`.
