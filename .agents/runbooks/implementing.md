# Implementation runbook

This is the repository-specific overlay for implementation custody.

## Repository surfaces

- Agent infrastructure belongs under `.agents/`.
- Ordinary project work belongs under `docs/`, `.agents/runbooks/`, `assets/`,
  `tools/`, or another existing canonical project home.
- `.agents/plans/` and `.agents/specs/` are the canonical repo plan homes.
- `INDEX.md` files are generated by `py -3 .agents/skills/generating-agent-mesh/scripts/generate_index_mesh.py --apply`; never hand-edit them.
- `.agents/plugins/marketplace-source` is a gitlink boundary and must not be
  changed by the mesh generator or local skill refresh.

## Local constraints

- Keep repo-local skills in `.agents/skills/adventures-*/` and preserve their
  exact names in `.agents/plugins/marketplace.json`.

## Patch boundaries

Patch may appear in visual canon and asset paths only as the project character;
do not introduce Patch agent, actor, owner, or execution-lane language.
