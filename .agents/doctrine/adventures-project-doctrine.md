# Adventures project doctrine

Status: active repository doctrine

This doctrine holds durable project law for Adventures of Patch. It is not a
skill, task recipe, or substitute for the detailed project runbooks.

## Identity

- Patch is the constant project character and visual canon unless Harley
  explicitly excludes him.
- Patch is not an agent, actor, owner, execution lane, or authority boundary.
- Agent infrastructure belongs under `.agents/`; ordinary project work belongs
  in its canonical project, asset, documentation, runbook, or script home.

## Source truth

- The repository, live issue/PR evidence, repo-tracked receipts, asset guides,
  manifests, sidecars, and direct canonical sources are authoritative for their
  respective facts.
- Uploaded zips, chat attachments, scratch files, memory, generated packages,
  and marketplace caches are context or evidence until the repo explicitly
  adopts them.
- Discover assets through `build/TAXONOMY.md`, tracked manifests, and the relevant
  canonical directories such as `build/`, `style/`, `published/`, and `workbench/`. Do not replace current repo truth with a hard-coded
  source-zip name or remembered path.

## Readiness law

- An adventure begins as a seed, not a production-ready artifact.
- Production requires a green frame and green asset readiness. The source must
  be runbook-ready before downstream production begins.
- A frame must make the lesson physically happen through a bounded world,
  visible anti-pattern and positive pattern, Patch agency as character,
  function mappings, continuity, story progression, and audience action.
- Generated images are candidates until the actual result is inspected against
  its authored direction and intended use. Preproduction references are not
  final scene art.

## Publication law

- Do not call work green without the required local validation and, for tracked
  mutation, exact branch/remote/PR publication proof.
- Keep local `adventures-*` skills as repository-owned sources. The pinned
  marketplace gitlink supplies selected standards; ambient plugins are neither
  subscribed nor projected into this checkout.
