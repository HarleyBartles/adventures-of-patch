# Patch Fairytales

Patch Fairytales are one-page pieces that are deliberately shallower than full Adventures of Patch. They lightly borrow a familiar story's core pattern, but Patch remains Patch rather than dressing as the story character. Each fairytale lands one concise agentic or operational principle.

A finished fairytale is a single approved page image. Its layout and source-image count can vary with the story hook. It is a peer product surface, not a future Adventure or deck.
